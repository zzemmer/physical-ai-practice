# Physical AI: Обучение с подкреплением для манипулятора Franka Panda

Отчет по учебной практике (3 семестр) в РТУ МИРЭА. 

## Стек
* **Языки:** Python
* **Библиотеки:** JAX, PyTorch
* **Среда:** Linux (Ubuntu), Docker

## Ключевые особенности
* Настройка симуляционной среды для 7-осевого манипулятора Franka Emika Panda.
* Запуск и мониторинг процесса обучения с подкреплением (Reinforcement Learning).
* Исследование проблемы **Sim-to-Real gap** (разрыв между физикой симулятора и реальным миром).
* Работа с Docker-контейнерами (запуск среды noVNC).

## Файлы
* `Report_PhysicalAI.pdf` — полный отчет по практике (включая графики обучения и анализ архитектур актора/критика).

## Результаты
В ходе работы была обучена модель, достигшая средней награды 1364.78 за 1001 итерацию.
